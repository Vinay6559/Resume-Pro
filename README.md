# Resume Pro – ATS-Friendly Resume Builder

**Build professional resumes. Showcase your skills. Make your next career move.**

Resume Pro is a modern, responsive, and interactive resume builder designed to help students, freshers, and professionals create clean, professional, and ATS-friendly resumes.

Built entirely using **HTML, CSS, and JavaScript**, Resume Pro provides an easy-to-use interface for creating, editing, customizing, and previewing resumes without requiring a backend.

## ✨ Features

- **ATS-Friendly Templates** – Professionally structured resume templates designed with applicant tracking system readability in mind.
- **Live Resume Preview** – See your resume changes as you build it.
- **Resume Customization** – Customize colors, fonts, and individual resume sections.
- **Responsive Design** – Works across desktop, laptop, tablet, and mobile devices.
- **Multiple Resume Templates** – Choose from different professional resume layouts.
- **Interactive Links** – Add clickable links to LinkedIn, GitHub, portfolios, projects, and certifications.
- **Resume Export** – Export resumes into supported formats such as PDF and DOCX.
- **Easy Editing** – Update your resume information and customize it whenever needed.
- **Modern Homepage** – A clean landing page introducing the Resume Pro platform.
